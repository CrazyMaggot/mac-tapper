# mac-tapper

Автокликер для macOS. Окно, в котором задаётся частота, кнопка мыши и одна
глобальная горячая клавиша. Нажатие клавиши запускает клики в точке курсора,
повторное нажатие останавливает.

## Требования

- macOS на Apple Silicon (проверялось на macOS 26, M4)
- [uv](https://docs.astral.sh/uv/) для управления окружением

## Запуск

```
uv sync
uv run tapper.py
```

Python 3.12 и Tk подтягиваются самим `uv`, ставить их отдельно не нужно.

## Разрешение системы

Программа отправляет события мыши и слушает клавиатуру глобально, поэтому
macOS требует «Универсальный доступ». Разрешение выдаётся не скрипту, а тому
приложению, из которого он запущен, то есть вашему терминалу.

Системные настройки, раздел «Конфиденциальность и безопасность», пункт
«Универсальный доступ», включить терминал в списке и перезапустить его.
При старте программа сама проверяет разрешение и предлагает открыть нужный
раздел настроек.

## Как пользоваться

1. Задать число кликов в секунду. Дробные значения допустимы.
2. Выбрать левую или правую кнопку.
3. Указать горячую клавишу: одна неслужебная клавиша, например `t`, `space`
   или `f6`. Сочетания с модификаторами не поддерживаются. По умолчанию `t`.
4. Нажать горячую клавишу в любом приложении. После задержки старта начнутся
   клики в текущей точке курсора, курсор можно двигать по ходу.
5. Повторное нажатие горячей клавиши или `Esc` останавливает работу.

Особенности поведения:

- Само нажатие горячей клавиши проходит в активное приложение, поэтому буква
  попадёт в текст.
- Буквенная клавиша задаётся по физической кнопке, а не по символу, поэтому
  работает и при русской раскладке.
- Горячая клавиша молчит, только когда окно таппера впереди и курсор стоит
  в одном из его полей ввода. В любом другом приложении она работает всегда.
- `Esc` слушается только во время работы.
- Клики над окном самой программы заблокированы, чтобы кликер не жал
  собственные кнопки.
- Частоту можно менять на ходу, кнопку только после остановки.
- Модификаторы не сбрасываются: если держите `Cmd`, клик уйдёт с `Cmd`.
- Настройки сохраняются в `tapper_settings.json` рядом со скриптом.

## Верхний ряд клавиш

На MacBook клавиши `F1`..`F12` по умолчанию отдают медиафункции: яркость,
громкость, режим фокусирования. В этом режиме нажатие `F6` не превращается
в событие клавиши и до программы не доходит вообще.

Либо включите «Использовать F1, F2 и остальные как стандартные функциональные
клавиши» в настройках клавиатуры, либо нажимайте их вместе с `Fn`, либо просто
возьмите букву.

Посмотреть, что именно видит программа при нажатии, можно так:

```
uv run tapper.py --keys
```

Двадцать секунд подряд выводится каждое пойманное нажатие: символ, физический
код клавиши и имя. Если нажатие в списке не появилось, эта клавиша до программы
не доходит.

## Про потолок частоты

Верхняя граница поля равна тысяче кликов в секунду, но столько не получит ни
одно приложение. Ограничение не в Python, а в самой macOS: каждое глобально
отправленное событие проходит через сервер окон.

Замеры на M4, macOS 26:

| Что мерялось | Результат |
| --- | --- |
| Планировщик интервалов без реальной отправки | до 1000 кликов в секунду |
| Отправка одного глобального события | около 1 мс |
| Реально отправлено при заказе 500 и 1000 | от 200 до 430 кликов в секунду |
| Принято обычным окном приложения | около 200 кликов в секунду |

Поэтому в окне выводится фактическая частота. Ориентируйтесь на неё, а не на
заказанную. Браузер дополнительно объединяет частые события мыши, клиент
удалённого рабочего стола ограничен сетью, а «Дублирование iPhone» может
отбрасывать синтетические события целиком.

Кнопка «Проверка доставки» открывает окно, считающее реально дошедшие клики.
Наведите на него курсор и включите таппер, чтобы увидеть свой потолок.

## Тесты

```
uv run pytest
```

Тесты покрывают разбор горячей клавиши и проверку границ ввода. Частота
проверяется измерением в окне проверки, а не тестами, потому что зависит от
реального времени и от загрузки системы.
